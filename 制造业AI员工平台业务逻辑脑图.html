底座 平台底座 · Hermes Agent Runtime ▾
Agent 注册中心：6 大内置 Agent（customer/sales/quotation/production/quality/ceo）启动自动注册，企业可再自建（受套餐 max_agents 限制）。
Tool 工具系统：Agent 调工具双重校验——manifest 声明 + 租户权限点，越权返回 403。
三层记忆：短期 / 长期 / 用户级，跨会话沉淀上下文。
RBAC 权限：所有业务表带 company_id，所有 API 经 require_company 校验，多租户隔离（跨企业 403）。
消息队列：Celery + Redis；RabbitMQ 企业版，QUEUE_MODE=auto 自动降级（rabbitmq→redis→内存）。
编排引擎：LangGraph StateGraph 意图路由（router→customer/sales/quotation），无 agent_id 时自动分流。
Soul 人设：企业自定义 system prompt，注入每个 Agent 头部（语气/边界/专业度）。
员工1 AI 客服 · customer_agent ▾
入口：web / WhatsApp / 企业微信 / 邮件 多渠道路由到本企业。
意图路由：intent_router → 判定为 customer（产品咨询/售后/用法）。
RAG 检索：knowledge.rag.search 检索企业知识库（top5）→ 注入上下文。
生成规则：仅依据资料回答，不编造；资料无答案则礼貌说明并转人工客服。
记录：对话存 Conversation，按 company_id 隔离，供经营大脑统计 AI 对话量。
员工2 AI 销售 · sales_agent ▾
意图路由：→ sales（有明确采购意向/数量/询价）。
结构化分析：LLM 输出 产品/数量/国家/购买意向/建议。
线索落库：_sales_with_lead 自动创建/更新 CRM 客户（source=agent）。
V2.1 AI 自主销售（全自动获客）
① 客户发现：关键词→模拟搜索→企业识别→网站分析→联系方式→写入 leads 表。
② 线索评分：行业匹配30 + 采购能力30 + 规模20 + 联系方式20 = 0~100； ≥90 A级70-89 B级<70 C级
③ 邮件跟进序列：D0 首封 / D3 跟进 / D7 提醒；中英文模板 + LLM 生成，首封自动带报价 PDF 附件。
④ 跟进节奏：discovered → contacted → replied → qualified → won / lost。
自动化：run_due_follow_ups（Celery beat 每日扫描到期线索发下一封）。
员工3 AI 报价 · quotation_agent ▾
意图路由：→ quotation（要求报价/价格/交期/付款方式）。
生成：LLM 输出 JSON（产品/数量/单价/总价/交期/付款方式/币种）。
落库：_quotation_with_record 自动建 Quotation，单号 QT{company_id}{8位}，total = 数量×单价。
PDF：/quotation/create 调用 quote_pdf 自动生成报价单 PDF。
状态机：draft → sent → accepted（已成交）/ rejected（已拒绝）。 注：截图中"待审"尚未接入后端
联动：报价后客户状态置为 quoted。
员工4 AI 生产计划 · production_agent ▾
数据源：MES 连接器（mes_api）拉取生产订单 / 产线负载 / 进度。
分析维度：① 是否延期 ② 生产瓶颈 ③ 优化建议。
对接：企业自有的 MES / ERP 系统（CRM·ERP·MES·QMS 集成）。
员工5 AI 质量工程师 · quality_agent ▾
数据源：QualityReport 质量报告（产线/不良率/缺陷类型）。
分析维度：① 是否存在异常 ② 可能原因 ③ 整改建议。
对接：企业自有的 QMS 质量管理系统。
经营联动：平均不良率被 CEO 日报聚合统计。
员工6 CEO 企业大脑 · ceo_agent ▾
数据聚合：询盘(Customer)、报价单(Quotation)、成交(accepted)、生产订单/风险(delay)、平均不良率、AI 对话量(Conversation)。
日报产出：销售情况 / 生产情况 / 质量情况 / 风险提示 / 明日建议。
价值：7×24 自动生成经营日报，管理者一眼掌握全局。
支撑 支撑系统与能力 ▾
知识库 RAG：企业资料向量化（Qdrant），客服/各 Agent 检索增强。
多渠道接入：web / WhatsApp / 企业微信 / 邮件，客户消息统一路由。
CRM 客户管理：状态机 new→following→quoted→won→lost；含客户 WhatsApp 字段。
业务系统对接：企业自有 CRM / ERP / MES / QMS（企业配，超管看总览）。
计费套餐：starter(1) / professional(5) / enterprise(自定义) → 限制 max_agents。
官网 CMS：对外介绍页（轮播/Hero/功能/客户/价格）+ 右侧悬浮客服（热线/QQ/微信）。
权限分层：企业管理用户配自有系统；平台超管只看哪家接通。
