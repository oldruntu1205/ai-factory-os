## 5. 契约缺陷修正（L2 对 L1 产物的结构性修复，已记录）

P1 契约存在**自身不可满足**的写法，静态门禁 188 项全绿也没发现：

```json
"context": {"$ref": "common-context.json", "properties": {...}}
```

JSON Schema 2020-12 规定：与 `$ref` **同级**的关键字一律被忽略。于是同级的
`properties`（要求 factory_id/task_id 非空）完全无效，被引用的
`additionalProperties: false` 生效 —— 该节点**没有任何实例可满足**
（只给两个键 → 缺 7 个 required；给九个键 → 被 additionalProperties 拒）。

- 修复：改成 `allOf` 覆盖式表达，共 11 处，涉及 `p1-classification` /
  `p1-governance` / `p1-token-vault` / `p1-readonly`。
- 工具：`scripts/fix_p1_context_nodes.py`（幂等、可重跑）。
- **P0 的 12 个契约文件未改动**，其哈希仍由 P1 门禁锁定并通过。
- 防复发：新增 `tests/contracts/test_contract_meta_validation.py`，
  用元模式 + 显式同级关键字检查；已用 `scripts/inject_ref_sibling_defect.py`
  注入原缺陷验证它**确实报红**。

## 6. 已知限制（**不得**当成已实现）

1. **无真实内容解析**：分类依据登记规则把引用映射到等级，没有读取正文/OCR/附件实际内容（属 P2 的 adapter 与对象存储）。
2. **DLP 是占位**：`dlp_passed` 由出域矩阵决定；没有真正的可重识别字段扫描与原文识别规则。
3. **输出扫描是声明**：`output_schema_passed` / `output_leak_scan_passed` 恒为 true，没有实现泄露扫描器。
4. **Vault 未加密**：映射落本地 JSONL（与日志分离），没有密钥域、加密与销毁策略；Vault 版本是 Mock。
5. **知识库是登记表内 Mock 文档**，不是 V2.1 的 Qdrant；真实向量索引的租户/工厂/岗位分区隔离属 P2。
6. **审计无追加存储保证**：落 JSONL；outbox 补送、保留策略、审计故障可靠性待冻结。
7. **认证仍是占位**：仍只校验"存在 Bearer + 服务身份登记"，未校验真实签发方与受众。
8. **队列未实现**：本地故障时按契约返回 `permit=false` / 503，没有真正的排队状态映射（待冻结）。
9. **P0 未触碰 `backend/`**：既有单体一行未改。
