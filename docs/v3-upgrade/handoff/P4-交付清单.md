## 3. Guard 判定顺序（§9 硬顺序，逐字对齐契约枚举）

契约 `p4-guard.json` 的 `Check.stage` 枚举与实现 `edge.GUARD_STAGES` **完全一致**：

```
structure → freshness_timeout → ood_drift → version → permit_policy
→ device_parameter_allowlist → interlock → budget → confidence
```

**不可覆盖项**（响应里以 const false 表达，且有变异测试）：
- `human_approval_overrides_hard_checks = false`（§9：人工批准也不能覆盖硬互锁）
- `confidence_overrides_hard_checks = false`（§9：置信度优先于**无**）
- 置信度必须是**经独立数据校准**的任务级指标，不接受 LLM 自报数字

## 4. 七态发布状态机（§12）

```
DRAFT → SCHEMA_FROZEN → CALIBRATED → SHADOW → APPROVED → ACTIVE → REVOKED
```
- 只允许**相邻推进**；跳态 409；`REVOKED` 为终态（不可再出发）。
- **行为性变化**（模型/Schema/特征提取器/tokenizer/校准参数/动作映射）⇒
  旧台账 `REVOKED` + `approval_current=false`，并建替代 DRAFT；
  回到的阶段取"最靠前"的那个（如 model+schema 同变 ⇒ 回 `SCHEMA_FROZEN`）。
- 非行为性变更走重开门禁 ⇒ 409 `GATE_REOPEN_REQUIRES_BEHAVIORAL_CHANGE`（防绕过）。

## 5. 已知限制（务必随送审一起看）

1. **A12 未覆盖**：无目标硬件 manifest、无分位延迟实测、无 14 天真实覆盖报告。
   门槛与评估**机制**已备，**数据**属外部依赖，不得用 Mock 替代。
2. **控制写禁用是本地语义断言**，不是真实网络 ACL 实测——A09 的物理隔离证据仍缺。
3. **断连/重连/重启演练全部是语义层模拟**（A10），未在真实边缘节点做。
4. **spool 的本地持久化是共享 journal**：真实边缘节点需要独立的本地存储与本地幂等，
   当前用同一 journal 模拟，跨进程原子性弱于现场磁盘。
5. **`/edge/v1/**` 在网络分层上属现场 API**（L5，不开放到公网）。
   本批为本地验证把 edge 路由挂在 `manufacturing-core` 上（沿用 P0 既有约定），
   **生产由 Edge Gateway 承载**（§14.1）。
6. 特征值、校准包、许可台账、互锁规格、动作白名单**均为占位引用**——
   真实内容属 §15 待冻结清单。
7. 发布台账的"现场节点"侧投影未实现（只有 control-plane 权威台账）。
8. §13 的 DDL 未在真实 PG 执行；Edge 侧存储边界是设计约束，非执行证明。

## 7. 本轮抓到的真缺陷（值得记住）

1. **路由表重复 owner 键 → 静默丢路由**：向 `ROUTES_BY_OWNER` 插入路由时误插进
   已有列表内部并多出一个同名 `"edge"` 键，Python 字典后者覆盖前者，
   整组 edge 路由消失。症状是接口 404，而**编译与契约静态门禁全绿**
   （契约文件与运行期路由表是两回事）。现已加机械自检：
   重复 owner 键检测 + **P4 契约路径可达性检测**（契约里每条路径都必须能被某个
   运行单元服务到）。
2. **同一语义两套术语**：`edge.py` 曾自带英文阶段名（`structural`/`ood`/`drift`/
   `license`/`scope`）与英文回退动作（`HOLD_BASELINE` 等），
   而契约枚举是 `structure`/`ood_drift`/`permit_policy`/… 与中文动作（`受控停机`）。
   两套术语在接口对接时必须翻译一次，而"翻译安全回退动作"正是最不该出错的地方。
   已全部以契约为准统一。
3. **误改 P0 既有路由**：给 `/edge/v1/decisions` 等既有路由误加了 `nested_context=True`，
   导致 P0 的 edge 用例从 403 变 400。已还原（由 P0 门禁抓到）。
4. **门禁自身漏跑测试文件**：`tests/contracts/test_contract_inventory_gates.py` 写好
   却从未被任何步骤引用，长期红着而门禁始终"全绿"。
   现已加**反向覆盖自检**：`tests/` 下没被任何步骤引用的测试文件自动补跑。
