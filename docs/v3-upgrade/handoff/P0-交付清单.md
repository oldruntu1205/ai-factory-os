## 5. 已知限制（**不得**当成已实现）

1. **无数据库**：Command/Task/Run 是内存 + JSONL，重启即空；每 owner 的 schema、DB role、RLS 未落地。
2. **无事件层**：没有 broker、outbox/inbox、至少一次投递；跨进程协作靠追加式 journal 模拟。
3. **无 Saga/补偿**：`Saga` 状态机只在契约里，代码没有实现。
4. **认证是占位**：只校验"存在 Bearer"，不校验签发方与受众；外部/内部/现场三种受众未分离。
5. **鉴权未做**：没有岗位、职责分离、委托范围的真实校验（登记表里的 `delegated_scopes` 只用于策略判定）。
6. **无 DLP / Tokenization / Token Vault**：数据分级只在准入时校验，没有脱敏与令牌恢复链路。
7. **Edge 未实现**：`/edge/v1/**` 只按契约返回"影子=无副作用 / 门禁未过=拒绝"，没有推理、校准与 spool。
8. **模型路由是 Mock**：只按登记表判断后端可达与等级匹配，没有真实调用、成本与健康度路由。
9. **端口覆盖是本地机制**：`V3_PORT_*` 仅为绕开 Windows 保留端口，不是生产配置。
10. **P0 未触碰 `backend/`**：既有单体一行未改。
