**§8 Edge-RLCD 与中心平台关系**
- Edge 是**现场决策节点**，与中心 Decision Fabric 可复用 Schema/校准/评测规范，

**§9 上线阶段（四阶段门禁）**
1. 离线验证 → 2. 两周影子运行 → 3. 受限闭环 → 4. 生产受限。
- 影子运行：**连续至少 14 天**生产比对、覆盖工况、偏差及延迟报告；
  **控制写入物理/网络禁用；无真实副作用**；覆盖与错误指标达到**事先冻结**门槛。
- 受限闭环：**签名许可、动作白名单、参数边界、现场批准、回退/回滚演练**；
  前三阶段通过、现场互锁有效，只开放批准设备与场景。
- **两周只是最低观察时间，不自动构成上线批准**；工况不足需延长。
- 模型/Schema/特征提取器/tokenizer/校准参数/动作映射发生**影响行为的变化**，
  **必须重做对应离线验证与影子发布门禁**，不能替换文件继续使用旧批准。

**§9 自动候选的合取条件（全部满足才可自动执行）**
闭环模式、校准包有效、Schema 通过、工况在适用域、输入新鲜、无异常漂移、
签名本地策略未过期、设备/参数在许可范围、互锁通过、执行预算未超限。
- 置信度是**经独立数据校准的任务级指标，不能取 LLM 自报数字**；
  多字段动作的**聚合算法必须在场景规格中冻结**。

**§9 判定优先级（硬顺序，必须高于置信度）**
缺失字段、NaN、越界、单位不明、超时、OOD、漂移、版本不匹配、互锁拒绝
**优先于置信度**。
- 安全回退动作由**设备工程师逐设备定义**（保持基线、停止自动调参、降速、受控停机），
  **不能由模型即兴选择**。
- **人工批准也不能覆盖硬互锁。**

**§9 断连与 spool**
- 中心断连时，已批准 Edge 场景在**签名策略和许可有效期内**可按现场规程自治；
  **策略过期、版本异常或本地持久化不可用则禁用 AI 新动作并回到设备基线**。
- **控制安全不依赖中心人工及时响应。**
- 现场事件使用**持久化本地 spool**，含 `edge_id` / `boot_id` / `sequence` / `event_id`
  与动作回执；重连按事件**去重补报**。
- **已执行设备动作只补报事实，禁止中心重放。**
- **历史待执行动作过 TTL 后不执行**；迟到事件**不覆盖**更新状态。
- 设备指令与回执也必须有**本地幂等 / 状态确认**。

6. **安全回退**：逐设备定义的固定回退动作（保持基线/停止自动调参/降速/受控停机），
