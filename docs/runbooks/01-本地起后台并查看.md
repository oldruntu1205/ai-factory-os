# 01 · 在浏览器里打开管理后台

## 前置

- Node ≥ 22（本机 v22.23.1）；`node --test` 与 `node --check` 都用到
- 仓库 venv：`backend\.venv`
- **不需要** npm 安装任何包（后台是零依赖 Node 服务）

## 三步

```powershell
cd "H:\制造业 AI 员工平台全量开发"

# 1) 起 8 个服务单元（标准端口 8101-8108）
backend\.venv\Scripts\python.exe tools\v3_dev_cluster.py start

# 2) 造一条走完整链路、带权威回执的命令（演示用）
backend\.venv\Scripts\python.exe tools\v3_dev_cluster.py demo

# 3) 起管理后台
node apps\web-admin\server.mjs
```

打开 **http://127.0.0.1:8300**

## 现场确认

```powershell
# 三个后端单元是否活着
Invoke-RestMethod http://127.0.0.1:8300/api/v3/health

# 演示命令的权威事实
$demo = Get-Content .v3-dev\demo.json -Raw | ConvertFrom-Json
Invoke-RestMethod "http://127.0.0.1:8300/api/v3/command?command_id=$($demo.command_id)"
```

`demo.json` 里的 `command_id` / `approval_id` 可直接粘进对应面板。

## 停

```powershell
backend\.venv\Scripts\python.exe tools\v3_dev_cluster.py stop   # 停集群
# 管理后台：结束 node 进程
Get-CimInstance Win32_Process -Filter "Name='node.exe'" |
  Where-Object { $_.CommandLine -like '*server.mjs*' } | ForEach-Object { Stop-Process -Id $_.ProcessId -Force }
```

## 预期看到什么（以及为什么）

| 面板 | 演示数据的结论 | 为什么是这个结论 |
| --- | --- | --- |
| 命令与权威回执 | **未过账**（`reason` = 权威回执确认**未**过账） | `posting_status` 恒为 `NOT_CONFIRMED`：真实过账凭证是外部依赖，尚未接入。**这是刻意的**（ADR-0005） |
| 批准可决定性 | **不可决定**（已成立，不可改判） | `demo` 里那条批准已经决定过；事实追加不可变 |
| 任务结论 | 需要自己建任务后查（见下） | 系统**没有任务列表接口**，只能按 id 查 |

## 建一条任务来查

```powershell
$body = @{
  tenant_id='tenant-demo'; factory_id='factory-demo'; actor_id='user-demo'
  employee_id='employee-planning'; trace_id='trace-manual'; data_class='C2'
  schema_version='1.0.0'; deadline_at='2026-12-31T00:00:00Z'
  idempotency_key="idem-$([guid]::NewGuid())"; input_ref='schedule-input-demo'
  input_schema=@{ type='object' }
} | ConvertTo-Json -Depth 5

$r = Invoke-RestMethod -Method Post -Uri http://127.0.0.1:8102/api/v1/tasks -Body $body `
  -ContentType 'application/json' `
  -Headers @{ Authorization='Bearer p0-test'; 'X-V3-Identity'='svc-hermes-runtime' }
$r.task_id
```

把它粘进「任务结论」面板。`ACCEPTED` ⇒ 显示**未过账 / 已受理，尚未提交执行**。
若显示「处理中」，那是缺陷——已修（任务不存在时必须明确"无法判定"）。

## 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 页面 502 `BACKEND_UNREACHABLE` | 集群没起或已停：`tools\v3_dev_cluster.py start` |
| 每次查询都 401 | **缺 `Authorization: Bearer`**。`X-V3-Identity` 只是租户归属，不是凭证 |
| `execution-record` 返回 400「工厂只读链路要求 task_id 非空」 | P1 Context 要求 `task_id` 非空（后台已自动补） |
| 改了页面没变化 | 服务端已发 `cache-control: no-store`，按 Ctrl+F5 强刷 |
| 端口 8300 被占 | `$env:V3_ADMIN_PORT=8400; node apps\web-admin\server.mjs` |
