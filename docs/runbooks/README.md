# 运行手册（runbooks）

上游 §15 要求 `docs/runbooks/`。这里写的是**本仓库实际用到的操作流程**，
不是通用模板——每一条都对应一次真实执行过的动作。

| [05-集群与端口规则.md](05-集群与端口规则.md) | 服务起不来 / 端口冲突 / 假失败 |

## 三条贯穿所有手册的铁律

1. **门禁必须串行跑。** 门禁会起真实多进程集群（8 个单元）；
   同时再跑一次（或后台任务）会**抢端口**，产生**假失败**。
   本项目已因此误判过两次（一次还被误当成代码缺陷）。
2. **判定函数不得读墙钟。** 读墙钟 ⇒ 结论不可复现 ⇒
   夹具迟早跨过某个常量时刻而**永久失败**，且表象会把人引向错误方向。
   判定时刻必须由调用方传入（见 ADR-0005 与 `approval.js` 的说明）。
3. **修完缺陷要补"改回去会被抓住"的变异。** 否则修复会在下次重构中被无声撤销。
