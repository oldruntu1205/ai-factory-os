## 七、性能优化记录（commit `b36d203`，2026-08-18）

1. **BM25 倒排索引**（knowledge/hybrid.py）：postings 倒排表 + doc_freq 预计算词频 + doc_len 缓存 + idf/avgdl 惰性重算
   - search 从 O(N) 全量扫描降为 O(候选文档 × query token) 哈希查频
